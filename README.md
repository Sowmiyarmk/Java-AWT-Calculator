# Java AWT Calculator

My first mini application project built using Java.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulo (%)
- Clear and Reset functionality
- Division-by-zero handling
- Window closing functionality

## Technologies Used
- Java
- AWT (Abstract Window Toolkit)
- AWT Event Handling

## Concepts Learned
- Classes and Objects
- Constructors
- Inheritance
- Interfaces
- Event Handling
- Conditional Statements
- GUI Development

## How to Run

1. Compile:
   `javac Calculator.java`

2. Run:
   `java Calculator`
